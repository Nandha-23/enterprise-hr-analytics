# Enterprise HR Analytics using Kaggle API

## Project Overview
This project performs enterprise-level HR analytics using a large HR dataset downloaded dynamically from Kaggle API.

The project includes:
- Data cleaning
- Employee analytics
- Department analysis
- Experience analysis
- Correlation analysis
- Interactive visualizations

---

## Technology Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Kaggle API
- Jupyter Notebook

---

## Features
- Dynamic dataset download using Kaggle API
- Data preprocessing and cleaning
- Interactive HR analytics visualizations
- Department-wise employee analysis
- Employee experience analysis
- Correlation heatmaps
